# SFM Code Workshop · 便携版

这是 **SFM Code Workshop v0.2.0** 的 Windows 便携包说明。

完整介绍、源码、构建方式和最新版本请访问项目主页。

## 运行

1. 解压整个目录到可写位置；
2. 双击 `SFMCodeWorkshop.exe`；
3. 首次启动会在用户数据目录创建示例工程与设置。

## 数据与隐私

- 工程、日志、用户模板、资源库和 AI 凭据保存在本机用户数据目录；
- 无遥测、不上传工程；
- AI 功能默认关闭，只有手动配置 Key 后才会联网；
- 日志不写入 API Key。
