# Icons

Line icons from [AI Canvas Icons](https://aicanvas.me/icons) (aicanvas.me).
Free Line style under the site's credit license; this attribution and the
one-line credit in each SVG are retained.

Downloaded 2026-11-22 from the public shadcn registry endpoints
`https://aicanvas.me/r/icon-<name>.json`. The SVGs are recoloured at runtime
with `currentColor`; no network access is used by the app.

Current set: `arrow-up-from-line`, `box`, `check`, `chevron-down`, `chevron-right`,
`circle-alert`, `circle-check`, `circle-dashed`, `circle-pause`, `circle-stop`, `circle-x`,
`code-sparkle`, `compass`, `copy`, `download`, `eraser`, `file-code`, `file-plus`, `folder`,
`folder-open`, `folder-plus`, `funnel`, `gamepad-2`, `gear`, `grip-vertical`,
`info`, `inbox`, `layers`, `layout-template`, `list`, `list-checks`,
`list-filter`, `list-todo`, `moon`, `package`, `package-open`,
`panel-left-open`, `pen`, `plugs-connected`, `plus`, `save`, `search`, `send`,
`shield-check`, `sparkles`, `sun`, `tag`, `timer`, `trash`, `triangle-alert`,
`workflow`, `x`.

Small sizes (≤14 px) are optically strengthened from the 1.5 px source stroke
to 1.9 px by `ui/icons.py`; the 24 px grid and one Line family are preserved.
